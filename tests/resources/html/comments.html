Release Notes: Version Three

Version three is out. The headline change is speed: the extraction pipeline moved to a compiled core and now processes a typical page in a fraction of the time the previous version needed.

The configuration file format did not change. Every key you already use is read the same way, and the defaults are the ones you know. We resisted the temptation to rename things.

Under the hood, the parser was replaced, the boilerplate heuristics were ported one by one with their test fixtures, and the fallback strategies now run concurrently where the page structure allows it.
