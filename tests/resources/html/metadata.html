Una página rica en metadatos

Esta página existe para probar la extracción de metadatos: título, autora, fecha de publicación, nombre del sitio, descripción, categorías, etiquetas, licencia e idioma. El motor debe recuperarlos todos desde las etiquetas meta, OpenGraph y JSON-LD sin necesidad del cuerpo del texto.

El segundo párrafo añade volumen suficiente para que el extractor principal considere el artículo como contenido válido y no intente ninguna estrategia de reserva.
