# Benchmark

rtrafilatura against [trafilatura](https://pypi.org/project/trafilatura/) 2.3.1 —
pytest-benchmark medians over six documents of the fixture corpus (`tests/resources/html/`): four synthetic
pages (minimal, article, comments, tables), PEP 8 and a Wikipedia article (121 KB and 236 KB of real HTML).

Generated by `make benchmark` on 2026-10-22 · Linux · cpython · commit 942fee3d.

## Reproduce

```bash
make benchmark    # uv run --group bench pytest -m bench --benchmark-json=bench.json, then the chart
```

Numbers move with the machine, the Python version and the engine releases; the committed chart is a snapshot,
`make benchmark` regenerates it. Both libraries run in the same process, interleaved by pytest-benchmark,
on the same fixtures.
